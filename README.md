# 年度计划清单项目

## 项目介绍
这是一个基于HTML5的个人年度计划清单应用，采用潜水员戴夫风格的马赛克卡通UI设计。

## 已实现的功能

### 1. 核心功能
- **努力区域**：分为运动、护肤、学习、饮食四个版块
- **奖励区域**：分为美食、旅游、购物三个版块
- **积分系统**：完成任务获得积分，积分可用于兑换奖励
- **数据保存**：使用localStorage自动保存数据

### 2. 子项目和周计划
- **子项目系统**：每个版块可创建多个子项目组
- **周计划功能**：可设置1-52周的周计划
- **任务管理**：每个子项目可添加、编辑、删除任务

### 3. 交互功能
- **任务完成**：点击复选框标记任务完成，获得积分
- **积分动画**：完成任务时显示积分增加动画
- **奖励兑换**：使用积分兑换奖励
- **进度显示**：每个版块显示完成度进度条

## 使用说明

1. **打开文件**：在浏览器中打开 `年度计划清单.html`
2. **添加子项目**：点击「+ 添加子项目」按钮
3. **设置周计划**：点击子项目旁边的 📅 按钮设置周数
4. **添加任务**：点击子项目内的 + 按钮添加任务
5. **完成任务**：点击任务旁边的复选框标记完成
6. **兑换奖励**：使用积分兑换奖励区域的奖励
7. **编辑任务**：直接点击任务名称或积分进行编辑
8. **删除任务**：点击任务旁边的 × 按钮删除

## 技术特点
- **响应式设计**：适配不同屏幕尺寸
- **动画效果**：流畅的积分动画和过渡效果
- **色彩丰富**：潜水员戴夫风格的海洋配色
- **用户友好**：直观的界面和操作流程
